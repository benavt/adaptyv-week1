# DD1_062 Y32D staging inputs

This directory contains FASTA inputs for the DD1_062 binder with Tyr32 mutated to Asp (Y32D), paired separately with the Human and Mouse EGFR D3 sequences from the species-intersection refolded complexes.

- Binder sequence: DD1_062, position 32 `Y -> D`
- Human input: `DD1_062_Y32D_Human_EGFR.fasta`
- Mouse input: `DD1_062_Y32D_Mouse_EGFR.fasta`
- FASTA order: designed binder first, EGFR D3 second
