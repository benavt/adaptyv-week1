# EGFR mechanism schematic

[Editable SVG](2026-10-06_egfr-ph-switch-schematic.svg). Redrawn from the mechanism interpretation in the existing 2026-10-06 methods source notes; the original supplied cartoon has not yet been located. Cyan DD1, magenta DD2, grey EGFR D3, green target histidines. The covalent tether is explicit. DD1 is not labeled as containing histidine: the assessed D46-130 DD1 segment has none. His protonation is depicted schematically, not as a binary assignment at either pH. This figure represents the proposed DD1/DD2 mechanism; the placeholder panel also contains designs from other branches.

The two panels are intended states, not validated pH-specific structures. Contacts, steric masking, reversible response, and relative state populations require further assessment. Figure labels use the nominal 7.4/6.5 design comparison; the separate ProtonPotts analysis used 7.3/6.5.
